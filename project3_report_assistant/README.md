# 带引用的文档检索与报告助手

这个项目是一个可解释的本地检索原型：从 Markdown 资料中按关键词检索段落，生成带 `文件#段落` 引用的回答；找不到依据时明确返回“没有在资料中找到依据”。它不调用外部模型，便于先验证需求、引用链路和评测方法，再决定是否接入模型。

## 运行

```powershell
python assistant.py "退款需要保留什么"
python evaluate.py
```

`evals.json` 是固定的合成评测集。`evaluate.py` 会输出通过数、命中率和引用位置。当前实现是可解释的关键词基线，简历中应称为“文档检索与引用助手原型”，不要写成已上线的大模型系统。

## 可展示的能力

- 把业务手册转成可检索、可追溯的回答
- 用固定问题集验证召回结果，而不是凭感觉展示几个例子
- 对无依据问题给出可解释的空结果
